# Kubernetes agent runner module v4.0.0

This breaking release installs runner chart `0.3.0` and configures outbound
HTTPS runner communication. Runner agents and deployment Jobs do not receive
NATS endpoints or credentials.

Callers provide the Ed25519 identity through `public_key_path` and
`private_key_path`. Simple and edge modes also require `gateway_url`. Private
gateway CAs can be supplied separately for the agent and deployment Job
namespaces.

`gateway_mode = "edge"` requires `outbox_enabled = true` and an RWX-capable
`outbox_storage_class_name` for multi-node clusters. `gateway_mode = "airgap"`
uses `airgap_gateway_secret` and `airgap_nats_existing_secret` for the
protected-side gateway and broker. Broker credentials stay inside the
protected compartment.

The module was validated with Terraform and OpenTofu across 24 test runs each.
Simple and edge execution were exercised locally. Air-gap resources render and
have automated coverage, but the physical diode path was not qualified.
