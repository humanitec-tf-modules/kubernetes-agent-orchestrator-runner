# Kubernetes agent runner module v3.0.0

This breaking release moves runner communications from direct HTTP calls to
NATS and updates the bundled runner chart to `0.2.0`.

Runner installations now require a NATS URL and exactly one supported
authentication method. `nats_token` is intended for local bootstrap and is
stored in Terraform state. Production installations should pre-create the
runner namespaces and subject-scoped NATS credentials, then use
`nats_existing_secret` with `create_namespaces = false`.

The runtime runner private key input was removed. The public registration key
remains required by the current control-plane registration API.

Simple and edge modes were exercised locally. The air-gap resources render and
have automated coverage, but the physical diode path was not tested and is not
qualified by this release.
